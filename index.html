About

About OpenUtility

A focused collection of small developer utilities designed to stay fast and easy to use.

Built for everyday development

OpenUtility brings common formatting, encoding, conversion, generation and text utilities into one simple browser workspace.

Browser-first

The current tools are implemented in the page itself. The site does not require an OpenUtility account or a server-side workspace to use the tools.

Open and lightweight

OpenUtility is hosted as a static website and is designed to work well on both desktop and mobile browsers.

Privacy

Privacy at a glance

What the current OpenUtility website stores and what it does not.

LOCAL

Tool data stays in your browser

The current implementation contains no application code that sends tool input to an OpenUtility API. Formatting, conversion, decoding and other tool operations run in the browser.

LOCAL

Preferences and history use local storage

Favorites, recently used tools, per-tool history and tool requests are stored in your browser's local storage. They are not submitted to an OpenUtility server by the current implementation.

URL

Shared links can contain URL state

Some navigation and sharing features use the URL. Avoid putting confidential information into a URL if you do not want that information included in a link you share or saved in browser history.

THIRD-PARTY

Google Fonts

The current page loads fonts from Google Fonts. Your browser therefore makes requests to Google's font infrastructure. If you want a fully self-contained deployment, the fonts can be self-hosted in a later performance/privacy pass.

BROWSER

Your browser still makes normal web requests

Hosting, DNS, HTTPS, GitHub Pages and your browser may create ordinary network requests and logs. This page does not claim that the website can prevent those platform-level requests.

Important: This privacy summary describes the current OpenUtility front-end implementation. It is not legal advice and does not override the privacy policies of hosting, DNS, browser or third-party services.
