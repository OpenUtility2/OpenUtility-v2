Privacy

Privacy
clear by design.

A plain-language summary of the current OpenUtility front-end data handling. This page is informational and is not legal advice.

Tool input

Supported tool operations are implemented in the browser. The current front-end does not send ordinary tool input to an OpenUtility API for processing.

Local storage

Features such as recent tools, favorites, history and locally submitted tool requests may use browser localStorage. This data remains on the device unless browser or user actions sync or expose it.

Shareable URLs

Some tools can encode state or identify a tool through the URL. Do not place confidential information into URLs you plan to share or keep in browser history.

Fonts and external resources

The current site loads Google Fonts. A browser may therefore make requests to Google infrastructure when fonts are requested.

Hosting and network logs

Normal hosting, DNS, HTTPS, browser and infrastructure requests can still generate technical logs outside the OpenUtility front-end. This page does not claim to eliminate those platform-level records.

Your responsibility

Do not paste passwords, private keys, tokens or other sensitive information into a tool unless you understand the tool and browser environment you are using.
